Why FishTVBox

为客厅屏幕做的界面

不追求复杂，只保留看电视最常用的三件事：直播、回看与点播。

01

直播与今日回看

解析 M3U / TXT 源，读取今日 EPG；无节目单时按小时生成当天回看时段。

02

电影海报墙

接入苹果 CMS V10 采集源，自动获取列表、搜索、详情与选集播放。

03

B 站短视频

抓取热门视频并按最长时长筛选，内嵌播放器直接观看。

04

手机即遥控

同一局域网打开 /remote，方向键、确认、返回、搜索与音量全部可用。

Deploy

拉取镜像，一条命令启动

镜像由 GitHub Actions 自动构建并推送到 GitHub Container Registry。

docker run
# 拉取并运行
docker run -d --name fishtvbox \
  --restart unless-stopped \
  -p 8686:8686 \
  -e TZ=Asia/Shanghai \
  -v "$(pwd)/data:/data" \
  ghcr.io/waterfish25/fishtvbox:latest
docker compose
# 在仓库目录执行
git clone https://github.com/waterfish25/FishTVBox.git
cd FishTVBox
docker compose up -d

# 或直接拉取已构建镜像
docker compose pull && docker compose up -d
